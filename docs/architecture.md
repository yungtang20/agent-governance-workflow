# Architecture

```text
Global governance
  -> project AGENTS.md
    -> optional Skills
      -> task-specific instruction
        -> evidence and verification
```

The shared kit defines formats and safety contracts. Each project retains authority over its data, APIs, tests, approvals, and production boundaries.

The lifecycle authority is [`ai-native-sdlc.md`](ai-native-sdlc.md). It governs delivery phases and gates; execution mode remains a separate routing dimension. Deployment documentation never grants deployment authorization.

Large guidance is loaded on demand from templates and documentation so the invariant system prompt stays compact.
