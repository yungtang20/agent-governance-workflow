# Pi Agent Governance

Use `execution_mode=SINGLE_EXECUTOR` and report `SINGLE_AGENT_MODE`.

For complex work, create a short Task Packet as a self-review checkpoint, then continue with the same executor. Do not claim independent reviewer or dual-model participation.

Preserve user changes, use minimum necessary edits, run relevant checks, inspect the Diff, and mark unknown external state `UNKNOWN`.

Use the risk-based lifecycle in `docs/ai-native-sdlc.md`. For complex work, keep a `templates/lifecycle-record.md`; skipped phases need `SKIPPED_WITH_REASON`, and deployment remains human-authorized.
