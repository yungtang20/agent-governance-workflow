# Role Matrix

| Role | Allowed | Forbidden | Deliverable |
|---|---|---|---|
| Executor | Explore, route, edit, test, verify, decide on review | Unauthorized irreversible operations | Changes and evidence |
| Reviewer | Read bounded packet, analyze, compare options | Edits, side effects, secrets, scope expansion | Numbered read-only recommendations |
| QA | Design and run regression checks | Weakening tests to obtain a pass | Test evidence |
| Librarian | Maintain indexes and provenance | Replacing project authority | Traceable records |
